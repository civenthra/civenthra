# Maintainers

The public maintainer identity is **Civenthra Maintainers / 文明穹顶维护组**.
The interim release lead and code owner is [@stonestorm2024](https://github.com/stonestorm2024).

Maintainers review code, rights and safety boundaries, security remediation,
and release evidence. Write access does not authorize publication of private
books, translations, media, identity data, credentials, or local operational
records.

New maintainers are nominated in a public issue, demonstrate sustained review
work, accept the Code of Conduct and security policy, and require approval from
the current release lead. Removal for inactivity is reversible; removal for a
security or rights incident must record a public rationale once disclosure is
safe.

At least two maintainers should eventually hold organization-owner continuity.
Until then, releases remain maintainer-led under `GOVERNANCE.md`.
