# Support

Use GitHub issues for reproducible, non-sensitive defects in the latest release.
Include the operating system, Python version, command, expected result, and a
minimal synthetic reproduction. Remove local paths, book text, account data,
logs containing conversations, voice data, portraits, and credentials.

This project provides best-effort community support. It does not provide
emergency, medical, legal, rescue, life-support, or certified engineering
support. For private security evidence, use `SECURITY.md`. Questions about a
third-party model or tool should be directed to that upstream project after
removing Civenthra-private material.
