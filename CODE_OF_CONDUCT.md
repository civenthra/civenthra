# Code of conduct

Civenthra contributors must communicate respectfully, critique work rather
than people, protect private material, and avoid harassment, discrimination,
threats, sexualized conduct, doxxing, or deliberate disruption.

Maintainers may edit, hide, lock, or remove violating content and may limit or
revoke participation. Decisions should be proportionate, documented privately
when personal data is involved, and open to review by another maintainer when
one is available.

Report ordinary conduct problems through GitHub's private repository reporting
and moderation tools. If a report also contains a vulnerability or private
technical evidence, use the route in `SECURITY.md`; never place that material in
a public issue. Immediate threats should be reported to the relevant platform
and local authorities rather than handled as a software issue.

This policy applies in project repositories, discussions, events, and public
representation of the project.
