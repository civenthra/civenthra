# Roadmap / 路线图

The roadmap communicates direction, not a delivery promise. Safety, privacy,
rights provenance, offline usefulness, and reviewability take priority over
feature count.

## Now — public foundation / 当前：公开基础版

- Publish a clean, history-isolated `0.1.0` source release.
- Keep every demo synthetic and every restricted backend disabled by default.
- Establish reproducible release evidence and contributor workflows.

## Next — usable offline learning / 下一步：可用的离线学习

- Complete the English browser interface and accessibility review.
- Add import previews, provenance metadata, translation labels, and local
  collection diagnostics without distributing source books.
- Define a rights-safe “one minute to understand a discipline” authoring format
  using original, public-domain, or explicitly licensed inputs.
- Add deterministic fallbacks when optional H3, avatar, or voice components are
  absent.

## Later — resilient offline system / 后续：韧性离线系统

- Offline education, life guidance, and AI-assisted video logs as separable
  modules with explicit trust boundaries.
- Verifiable knowledge updates, removable storage exchange, disaster recovery,
  multilingual content packs, and long-duration habitat simulations.
- Independent expert review for any safety-critical domain before operational
  use, including Mars-habitat scenarios.

## Non-goals for the current release / 当前版本非目标

- Distributing the planned 100,000-book private collection or its translations.
- Claiming flight, medical, rescue, life-support, or autonomous operational
  certification.
- Relicensing third-party models, voices, portraits, or generated outputs as
  Apache-2.0.
