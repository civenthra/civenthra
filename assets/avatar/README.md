# Local avatar assets

Portraits, voice references and generated character images are deliberately not
distributed with the source repository. They may contain a person's likeness,
voice biometric data, platform-specific creative assets or unclear generation
rights.

Set `avatar_portrait` in `config.local.json` to an image you are authorized to
use. The public repository must contain only this policy file unless a specific
asset has a recorded owner, source, license and redistribution permission.
